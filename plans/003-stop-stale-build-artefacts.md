# 003 — Stop TypeScript from emitting a `vite.config.js` that shadows `vite.config.ts`, and ignore local artefacts

- **Written against:** commit `8c0837e` (main).
- **Effort:** S · **Risk:** low · **Priority:** 3 (independent; can land first)

## Why

`frontend/` currently contains four **untracked, generated** files:

```
frontend/vite.config.js        (emitted Sep 30)
frontend/vite.config.d.ts
frontend/tsconfig.tsbuildinfo
frontend/tsconfig.node.tsbuildinfo
```

They are emitted by `tsc -b` (used during development) because `frontend/tsconfig.node.json` is a `composite` project with no output directory. **Vite loads `vite.config.js` before `vite.config.ts`** (its default lookup order is `.js`, `.mjs`, `.ts`, …). Today the two files are equivalent, but the next edit to `vite.config.ts` (e.g. the `/api` proxy) will be **silently ignored** by `npm run dev`. That is the same class of "the server is running old code" bug the team already hit with a stale uvicorn worker. The files are also not in `.gitignore`, so a `git add -A` would commit them.

Separately, two local-only files are protected only by the per-clone `.git/info/exclude` (which does not travel to new clones or worktrees):
- `/.dev-test-user.json`: a local QA login (contains a credential; do **not** open, print or copy it)
- `backend/.hypothesis/`: hypothesis test cache.

## Current state (verified)

`frontend/tsconfig.node.json`:
```json
{
  "compilerOptions": {
    "composite": true,
    "skipLibCheck": true,
    "module": "ESNext",
    "moduleResolution": "bundler",
    "allowSyntheticDefaultImports": true
  },
  "include": ["vite.config.ts"]
}
```
`frontend/tsconfig.json` has `"noEmit": true` and `"references": [{ "path": "./tsconfig.node.json" }]`.
`frontend/package.json` scripts: `"build": "tsc && vite build"`, `"test": "vitest run"`. CI runs `npx tsc --noEmit` and `npm run build`.

`.gitignore` (root) has Python/Node sections but no `*.tsbuildinfo`, no `frontend/vite.config.js`, no `frontend/vite.config.d.ts`, no `.dev-test-user.json`, no `.hypothesis/`.

## Scope

In scope: `frontend/tsconfig.node.json`, root `.gitignore`, deleting the four untracked generated files listed above.
Out of scope: `vite.config.ts` contents, `tsconfig.json` compiler options other than what step 2 names, CI workflow, `.git/info/exclude` (leave it), `.dev-test-user.json` itself (never open or delete it).

## Steps

1. **Send the node project's emit somewhere harmless.** In `frontend/tsconfig.node.json` `compilerOptions` add:
   ```json
   "outDir": "./node_modules/.tmp/tsconfig-node",
   "tsBuildInfoFile": "./node_modules/.tmp/tsconfig.node.tsbuildinfo"
   ```
   (`composite` projects cannot use `noEmit`; redirecting output under `node_modules/` keeps it out of the tree and out of Vite's lookup.)

2. **Same for the app project's build info.** In `frontend/tsconfig.json` `compilerOptions` add `"tsBuildInfoFile": "./node_modules/.tmp/tsconfig.tsbuildinfo"`. Change nothing else.

3. **Delete the stale generated files** (untracked, safe): `frontend/vite.config.js`, `frontend/vite.config.d.ts`, `frontend/tsconfig.tsbuildinfo`, `frontend/tsconfig.node.tsbuildinfo`. Before deleting, confirm each is untracked: `git ls-files frontend | grep -E "tsbuildinfo|vite.config"` must print only `frontend/vite.config.ts`. If it prints any of the four, STOP and report.

4. **`.gitignore`** (root): append a block:
   ```gitignore
   # Generated by tsc -b / local tooling
   *.tsbuildinfo
   frontend/vite.config.js
   frontend/vite.config.d.ts
   backend/.hypothesis/

   # Local QA login used by headless browser checks (never commit)
   .dev-test-user.json
   ```

5. **Prove it** from `frontend/`:
   - `npx tsc -b` then `ls vite.config.js vite.config.d.ts *.tsbuildinfo` → "No such file" for all four.
   - `npx tsc --noEmit` → exit 0.
   - `npm run build` → succeeds (this writes `dist/`, already ignored).
   - `npx vitest run` → all pass.
   - From repo root: `git status --short` shows only `.gitignore`, `frontend/tsconfig.json`, `frontend/tsconfig.node.json` modified (plus `plans/` if still untracked).

## Done criteria

- After `npx tsc -b`, `test ! -e frontend/vite.config.js && test ! -e frontend/tsconfig.tsbuildinfo` succeeds.
- `git check-ignore .dev-test-user.json backend/.hypothesis frontend/vite.config.js` prints all three.
- tsc / build / vitest all green.

## Maintenance notes

- If a later change adds another `references` project, give it its own `outDir` under `node_modules/.tmp/` too.
- If someone switches `vite.config.ts` to `.mts`, the ignore rule for `.js` still protects the lookup.

## Escape hatches

- If `npx tsc -b` errors with "TS6310 / referenced project may not disable emit" or similar after step 1, revert step 1 and STOP with the exact error.
- Never print the contents of `.dev-test-user.json`.
